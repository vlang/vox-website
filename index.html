Questions

Good to know.

The short answers about Vox and where it is headed.

What is Vox?

An open-source browser engine written in V. It is still in alpha, but builds are available for Windows, macOS and Linux.

Why is it fast?

Vox focuses on performance and minimal resource usage. In a Hacker News test with JavaScript disabled it rendered about four times faster than Chrome and used less memory and CPU.

Does it support extensions?

The goal is for Chrome addons to work automatically. Vox also has a built-in ad blocker based on uBlock Origin and blocks cookie warnings.

Can I help build it?

Yes. The source is on GitHub and development happens in the open. Join the Discord if you want to contribute.
